# Public test vectors

The JSON files contain the ML-KEM-768 groups extracted without changing test
values from NIST's ACVP-Server sample `internalProjection.json` files.
`sources.json` pins the upstream commit, original paths and complete-file
SHA-256 hashes. Tests run offline; no fixture download is needed during a build.

There are 25 key generation cases, 25 encapsulation cases, 10 decapsulation
cases and 20 key checks. The runner additionally decapsulates the 25 valid
encapsulation fixtures: 105 assertions in total. Passing these regressions does
not constitute CAVP or FIPS 140-3 certification or an independent audit.

`legacy-v1.rsp` was generated by the unmodified libzupt commit `77e3d0c`.
Its private key is deliberately public, for migration testing only. Never use
these keys to protect real data.
